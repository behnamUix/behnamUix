## 👨🏻‍💻 About Me | درباره من

من **علی محجوب** هستم؛ توسعه‌دهنده Android با بیش از ۴ سال تجربه عملی و پروژه‌محور در توسعه اپلیکیشن‌های اندرویدی با Kotlin.

تمرکز اصلی من طراحی و پیاده‌سازی اپلیکیشن‌هایی با معماری اصولی، کد قابل نگهداری، عملکرد مناسب و تجربه کاربری مطلوب است.

در پروژه‌هایم از تکنولوژی‌های مدرن اکوسیستم Android استفاده می‌کنم و به توسعه اپلیکیشن‌های چندسکویی با **Kotlin Multiplatform** نیز علاقه‌مندم.

### حوزه‌های تخصصی من

- توسعه اپلیکیشن‌های Native Android
- طراحی رابط کاربری با Jetpack Compose
- پیاده‌سازی Clean Architecture و معماری‌های MVVM و MVI
- مدیریت وضعیت و پردازش‌های ناهمگام با Coroutines و Flow
- طراحی ساختارهای Feature-Based و ماژولار
- توسعه منطق مشترک با Kotlin Multiplatform
- بهبود کیفیت کد، نگهداری و توسعه‌پذیری پروژه‌ها

**Technical Highlights**

| Technology | Implementation |
|---|---|
| Language | Kotlin |
| Multiplatform | Kotlin Multiplatform |
| UI | Compose Multiplatform |
| Architecture | Clean Architecture |
| Presentation | MVI |
| Dependency Injection | Koin |
| Asynchronous | Coroutines & StateFlow |
| Data Layer | Repository Pattern |
| Serialization | Kotlinx Serialization |
| Structure | Feature-Based Architecture |

**Key Features**

- تفکیک لایه‌های Domain، Data و Presentation
- مدیریت وضعیت رابط کاربری با MVI
